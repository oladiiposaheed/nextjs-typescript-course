# Lesson 3.2: Nested Folders

Folders inside folders create deeper URLs.

## Structure

| File                            | URL                 |
| ------------------------------- | ------------------- |
| `app/page.tsx`                  | `/`                 |
| `app/shop/page.tsx`             | `/shop`             |
| `app/shop/books/page.tsx`       | `/shop/books`       |
| `app/shop/electronics/page.tsx` | `/shop/electronics` |

Each `page.tsx` = a valid URL.
